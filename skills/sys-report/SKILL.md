# Системный отчёт (Windows)

Собери сведения о системе и верни пользователю структурированную сводку.

1. Запусти скрипт `scripts/sys_report.py` (python):

```
python "ПУТЬ/sys-report/scripts/sys_report.py"
```

2. Скрипт печатает JSON: `{os, version, arch, cpu, cores, ramTotalGb, ramFreeGb, uptimeHours, disks: [{drive, totalGb, freeGb, freePct}], hostname, user, python}`.

3. Оформи для пользователя читаемую русскоязычную сводку:

- ОС и версия
- Процессор и ядра
- ОЗУ (всего / свободно)
- Диски: занято / свободно в ГБ и проценты
- Аптайм
- Имя ПК / пользователь

4. Если в запросе была просьба «сохранить» — запиши отчёт в файл `system-report.txt` в рабочей папке и в `result` укажи путь к нему. Иначе верни `{"done":true,"result":"<сводка>"}` прямо в сообщении.

Не используй powershell и wmic — только скрипт из этой папки.
